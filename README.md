# 📱 React Native en Español App

Bienvenido a **React Native en Español App**! Esta aplicación está diseñada para ayudarte a aprender y desarrollar aplicaciones móviles usando React Native. 🚀

## 🚀 Comenzando

Para comenzar con el desarrollo de esta aplicación, sigue estos pasos:

1. Clona el repositorio:
   ```sh
   git clone https://github.com/tu-usuario/reactnativeenespanolapp.git
   ```
2. Instala las dependencias:
   ```sh
   cd reactnativeenespanolapp
   npm install
   ```
3. Inicia la aplicación:
   ```sh
   npm start
   ```

## 📚 Scripts Disponibles

En el proyecto, puedes ejecutar los siguientes scripts:

- `npm start`: Inicia la aplicación en modo de desarrollo.
- `npm run android`: Inicia la aplicación en un emulador de Android.
- `npm run ios`: Inicia la aplicación en un emulador de iOS.
- `npm run web`: Inicia la aplicación en el navegador web.
- `npm test`: Ejecuta las pruebas.
- `npm run lint`: Ejecuta el linter para encontrar y corregir problemas en el código.
- `npm run reset-project`: Resetea el proyecto.

## 🛠️ Dependencias

Este proyecto utiliza las siguientes dependencias principales:

- `expo`
- `react`
- `react-native`
- `@react-navigation/native`
- `@expo/vector-icons`

Para ver la lista completa de dependencias, consulta el archivo `package.json`.
